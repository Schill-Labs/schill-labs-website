Structured dry-fire practice.

What it does

What's in it.

Timed drills

Run drills against the clock instead of guessing at your pace.

Par times

Set a par, chase it, tighten it. The classic way to build speed.

Session log

Every session recorded, so progress is a chart instead of a feeling.

Custom routines

Build practice around what you're working on: draws, transitions, reloads.

No clutter

A plain, readable interface you can use with the phone on a table.

Dry fire only

Built for practice with a cleared, unloaded firearm. Always verify. Safety rules come first.
